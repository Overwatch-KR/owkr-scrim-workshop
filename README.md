# OWKR 내전 워크샵

OWKR 내전에서 사용할 Overwatch 사용자 지정 게임 모드입니다.

**준비 중** · 내전에 사용할 모드와 게임에서 불러올 수 있는 워크샵 공유 코드는 공개 전입니다.

**[OWKR Discord](https://discord.gg/overwatchkr) · [내전 참가 안내](https://overwatch-kr.github.io/owkr-docs/participation)**

## 관련 OWKR 서비스

- [OWKR Match](https://github.com/Overwatch-KR/owkr-balance) · 내전 팀 편성
- [OWKR 문서](https://overwatch-kr.github.io/owkr-docs/) · 내전 규칙과 참가 안내
- [OWKR 관리자 시험](https://owkr-exam.vercel.app/) · 내전 운영진 선발 시험
- [시간을달리는소녀](https://github.com/Overwatch-KR/owkr-gather-bot) · Discord 내전 모집
